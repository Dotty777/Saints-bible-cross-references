# Staging candidate reviews (drafts)

Reviews for every staging cross-reference candidate that was still awaiting review and had no curated counterpart: **37,007 entries** in 64 books — 13,293 supported, 16,489 weak, 7,225 unsupported.

Each file holds `saints-xref-review` chapter records keyed by the entry’s `data-sxe-edge`, with the verdict, category, summary, why-it-matters line, an optional note, the staging entry ID and the Saints readings the entry displays. Nothing has been written to staging.

How they were made: every candidate’s source verse and displayed Saints reading(s) were read and judged against the Saints wording (long ranges were shown up to about 700 characters). 1,925 entries whose cited passage has no counterpart in this edition, or whose imported source verse is unidentified, carry a standard explanation instead of an interpretive review. 379 reviews that quote Hebrew-based or paraphrased wording carry a note saying so. These are AI-assisted reviews and have not been checked by a person.
