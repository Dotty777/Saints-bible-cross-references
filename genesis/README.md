# Genesis — Saints Bible cross-references

Genesis 1–19 is complete at the initial curated cross-reference stage: **496 source verses and 1244 distinct source/target-passage pairs**. Later chapters remain pending. Next: **Genesis 20:1**.

Completed means the initial curated cross-reference pass: the source verse and every listed target passage were read in the pinned Saints-Translation English records, and each retained pair has a specific explanation. It does not mean every possible biblical connection has been exhausted, or independent scholarly approval.

## Files

- [Genesis.html](Genesis.html): readable completed records, with expandable matching-passage text and retained source verse anchors. Download and open in a browser.
- [Genesis.txt](Genesis.txt): completed source verses, matching references, relationship categories and explanations.
- [verses.json](verses.json): all 1,531 source verse units in the 50-chapter Genesis inventory; completed and pending statuses are explicit. Completed entries contain exact target text, stable pair IDs and source hashes.
- [editorial-notes.json](editorial-notes.json): particular interpretive and numbering cautions from this review.
- [source-checks.json](source-checks.json): actual evidence, pinned source files, method and pending review.
- [verification.json](verification.json): validation of coverage, pair uniqueness, target identities and evidence hashes.
- [RESTORE.md](RESTORE.md): recovery and correction procedure.
